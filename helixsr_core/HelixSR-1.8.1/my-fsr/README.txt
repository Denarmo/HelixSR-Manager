Want FSR 4 (or another FSR version) next to HelixSR in every game?

1. Put the FSR DLL into this folder (any file name, for example amd_fidelityfx_upscaler_dx12.dll).
2. Run the HelixSR setup again and press Enter for your games.

Only one game? Put the DLL into the my-fsr folder inside that game's HelixSR folder (next to the game's .exe)
instead and start the game again; no setup needed.

In the game press Insert (OptiScaler's menu), then Upscaling tab > Upscalers > FFX Upscaler, and pick it there:
it is listed by its version, for example "FSR 4.1.1". HelixSR stays the default ("FSR HelixSR (3.1.5)").
To go back: take the DLL out of this folder and run the setup again.
