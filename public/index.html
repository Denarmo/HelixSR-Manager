Custom FSR & FidelityFX Manager

With HelixSR's OptiScaler integration, you can also inject custom AMD FidelityFX DLLs (such as FSR 4.1.1) side-by-side with HelixSR!

How Custom FSR Works

When a game is installed via OptiScaler mode, a HelixSR/my-fsr folder is created inside the game's executable directory. Any FidelityFX upscaler DLL placed into that folder is dynamically exposed in the in-game OptiScaler overlay!

1
Launch your game with HelixSR installed.
2
Press the Insert key to open the in-game OptiScaler HUD overlay.
3
Navigate to Upscaling tab → Upscalers → FFX Upscaler.
4
Switch between FSR HelixSR (3.1.5) (default) and any custom FSR DLL (e.g. FSR 4.1.1) in real-time!

About HelixSR Manager

HelixSR is an unofficial community project by lonewolf0622 that acts as a drop-in FSR 3.1 replacement for Direct3D 12 games, executing NVIDIA's DLSS Model E neural network using standard compute shaders on AMD GPUs (RDNA 1, RDNA 2, RDNA 3, RDNA 4).

HelixSR Manager provides a high-performance desktop management interface for Windows and Linux (SteamOS), allowing PC gamers to inspect, install, update, and manage HelixSR mods across all their installed titles.
